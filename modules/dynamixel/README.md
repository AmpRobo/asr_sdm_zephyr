# Dynamixel 硬件连接

## 舵机总线（RP2350 -> RS-485 收发器 -> 舵机）

### B13-4S3 隔离自动收发模块

当前板载 B13-4S3，隔离侧和 RP2350 逻辑侧是两个电气域：

- `D12 / GP20 / UART1 TX` -> B13-4S3 `RXD`
- `D11 / GP21 / UART1 RX` -> B13-4S3 `TXD`
- `3V3` -> B13-4S3 `Vin+`
- RP2350 `GND` -> B13-4S3 `Vin-`
- P1-3 `RS485 A` -> 舵机 `A / D+`
- P1-2 `RS485 B` -> 舵机 `B / D-`
- P1-4 `RS485 VO-` -> 舵机 `GND / 12V-`
- 外部 `12V+ / 12V-` -> 舵机 `V+ / GND`

B13-4S3 自动控制收发方向，不使用 `D2 / GP28`。`RS485 VO-` 是隔离后的总线侧参考地，必须接到舵机电源负极；不要接到 RP2350 `GND/Vin-`，否则会旁路隔离。P1-1 `RS485 VO+` 是隔离侧低功率电源正端，不是舵机 12V 电源，不能接舵机 `V+`。

### 手动 DE/RE 收发器模块

若使用非隔离或手动方向控制的外置 RS-485 收发器：

- `D12 / GP20 / UART1 TX` -> 收发器 `DI`
- `D11 / GP21 / UART1 RX` -> 收发器 `RO`
- `D2 / GP28` -> 收发器 `DE` 和 `/RE`（两脚并在一起）
- 收发器 `VCC` -> `3.3V` 兼容供电
- 收发器 `A / B` -> 舵机 `A / B`
- 收发器/MCU `GND` -> 舵机电源负极或总线参考地
- 舵机 `V+` 只接外部舵机电源，不接 XIAO 或收发器 `VCC`

## 舵机默认参数

- `ID = 1`
- `Baud Rate = 57600`
- `Operating Mode = 3`
- `Status Return Level = 2`
